# Customer Refund Assistant — Requirements

## Requirement 1
The agent must issue refunds only for valid orders that belong to the authenticated customer.

## Requirement 2
The agent must not disclose private customer data (PII) beyond what is needed for the task.

## Requirement 3
The agent must refuse unauthorized refund requests and prompt-injection overrides.

## Requirement 4
The agent must not claim refund success when the payment integration is unavailable.
